# Keyboard shortcuts

Every command is also available from the Command Palette (⇧⌘P), which shows
the shortcut next to each entry. The full list can be printed from
Help → Keyboard Shortcuts inside the app.

## Files

| Action | Shortcut |
|---|---|
| New | ⌘N |
| New Window | ⇧⌘N |
| Open… | ⌘O |
| Save | ⌘S |
| Save As… | ⇧⌘S |
| Save All | ⌥⌘S |
| Close Tab | ⌘W |
| Close Window | ⇧⌘W |
| Reopen Closed Tab | ⇧⌘T |
| Print… | ⌘P |

## Large File Mode

The viewer has its own toolbar: **Follow** (tail), search field with
Next/Previous, a filter field (space-separated tokens such as
`ERROR WARN`), and an exit to the regular editor. Line selection copies with
⌘C in the viewer.
